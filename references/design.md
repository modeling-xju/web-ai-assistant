# 挂件的视觉决策

这份文档解释自建挂件为什么长这样，以及改的时候哪些做法会让它一眼看出"这是 AI 拼出来的组件"。

## 默认外观的取向：墨与纸

默认主题刻意避开了一整套网站在用的默认答案。对照着看：

| 大家默认会做的 | 这里做的 | 为什么 |
|---|---|---|
| 蓝紫渐变圆球按钮 | 墨色方块，右下切一角（`clip-path`） | 圆形渐变球是"AI 客服"这个品类的视觉陈词滥调，看到就出戏。切角是个小破格，成本极低但对识别度贡献很大 |
| 对话气泡带小尾巴，灰底圆角 | 助手侧不用气泡，用一条 2px 朱砂竖线起头 | 去掉气泡后文字直接落在纸面上，视觉噪音小很多；竖线承担"这是谁在说话"的功能，比气泡更轻 |
| 层层阴影堆叠层次 | 发丝级 1px 描边 + 留白 | 阴影在深色站点上会糊成一团，描边不会。而且描边在投影和低亮度屏上更稳 |
| 到处是大圆角（12–20px） | 3px 圆角 | 大圆角会立刻让挂件显得"不属于"那些用直角/微圆角的严肃站点 |
| 满屏一个色系 | 全灰阶 + 唯一的彩色只出现在"正在生成"和未读上 | 彩色是信号，不是装饰。用得越少，越能指路 |
| 欢迎语 + "我可以帮你…" + 三个功能介绍 | 一句业务化的问候 + 2–4 条真实问题 | 访客不需要理解你是谁，需要的是"我的问题能不能在这儿问"。问题示例同时是功能说明和入口 |

## 改配色

所有颜色走 CSS 自定义属性，在 `ai-assistant.css` 的 `.waa` 规则里：

```css
.waa {
  --waa-accent: #D8402F;   /* 唯一的彩色：流式光标、未读点、助手侧竖线 */
  --waa-bg:     #FBFAF7;   /* 面板底色 */
  --waa-ink:    #17161A;   /* 主文字，也是用户气泡和按钮的底色 */
  --waa-muted:  #6E6A66;   /* 元信息 */
  --waa-line:          rgba(23,22,26,.14);  /* 发丝描边 */
  --waa-line-strong:   rgba(23,22,26,.34);  /* 面板外框 */
  --waa-radius: 3px;
}
.waa[data-theme="dark"] { /* 深色模式覆盖上面几个 */ }
```

也可以不改文件，用挂件参数直接覆盖：

```js
WebAIAssistant.mount({ accent: '#0F766E', radius: '2px' });
```

**要融入站点，改这四个就够了**：`--waa-accent` 取站点的主色、`--waa-bg` 取站点卡片底色、`--waa-ink` 取站点正文色、`--waa-line` 取站点分隔线色。**不要**去改布局结构——那部分是按"任何站点都能用"调的。

想完全接管样式就把内置样式表整个换掉（`css` 传字符串，或 `cssUrl` 指自己的文件）。但要注意：**换掉的必须是全部**，因为内置样式表里有 `:host { all: initial }` 和各元素的 reset，少了这些宿主页面的全局样式会渗进来。

## 排版

- 正文字号 14px、行高 1.62。挂件通常压在内容上，行高太紧会显得局促。
- 元信息（"在线"、"正在回答"、代码块语言）用等宽字体 + `letter-spacing`。这一层等宽字给了它一点工程感，也和不规则的像素密度配合得比无衬线更好。
- 助手名 `letter-spacing: 0.08em`。中文加字距要克制，0.05–0.1em 之间，再多就散了。
- 代码块自带语言标签和复制按钮。**复制按钮不是装饰**——访客拿到一段配置时的第一个动作就是复制。

## 动效

- 面板出现 `200ms` 的 `translateY(10px) + scale(0.985)`，从启动器方向展开。再慢就显得拖沓，再快就看不见。
- 流式光标用 `steps(2)` 硬闪，不是渐变淡入淡出——硬闪更像终端，和等宽字一层的气质一致。
- 启动器悬停时整块变成主色，不做缩放。缩放会让 `clip-path` 的切角看起来在抖动。
- `prefers-reduced-motion` 下全部关掉，包括光标闪烁。

## 反"AI 味"检查清单

改完对着过一遍，命中任何一条都值得推翻重做：

- [ ] 有没有蓝紫渐变？
- [ ] 有没有到处铺满描述性文案（"这是一个 AI 助手，你可以向我提问"）？
- [ ] 有没有用居中标题 + 副标题的经典结构（挂件面板里不需要这种"着陆页语法"）？
- [ ] 圆角是不是一水儿的大圆角？
- [ ] 阴影是不是叠了三层？
- [ ] 图标是不是随便找的通用聊天气泡？
- [ ] 问候语是不是"你好，我是AI助手，很高兴为你服务"？
- [ ] 每个颜色是不是都能说出它为什么在那儿？

最后一条最重要。**说不出理由的装饰就是噪音。**

## 别做的事

- **不要为了"更醒目"把面板做成 600px 宽。** 挂件是辅助通道，压住正文内容会招人烦。384px 是能舒服阅读一行的下限附近，够用。
- **不要 `autoOpen: true`。** 访客刚落地的第一秒是最不该被打扰的时刻，自动弹窗的转化率远低于"他看到问题了主动点"。这个参数存在是为了少数内部系统场景，不是默认推荐。
- **不要在挂件里放公司 Logo 大图。** 52px 的启动器里塞不下可辨识的 Logo，放大又喧宾夺主。
- **不要给输入框做"AI 正在思考…"的假动画。** 流式输出本身就是最好的进度指示。
